# 🎂 make-birthday-happier

사진을 고르고 이름과 날짜만 바꾸면, 생일 카드 **JPG 1장**이나 세로 **MP4 영상**을 만들어 주는 웹 페이지예요.
설치 없이 폰(안드로이드)과 PC 브라우저에서 바로 쓸 수 있어요.

**👉 https://bigupmy.github.io/make-birthday-happier/**

## 쓰는 방법

1. 위 주소를 **크롬**(또는 엣지)으로 열어요.
2. 위쪽에서 만들 것을 골라요.
   - **📷 이미지 (JPG)**: 사진 1장 → 틀 4종 중 선택 → JPG 1장 (1080×1350)
   - **🎬 영상 (MP4)**: 사진 3~5장 → 틀 3종 중 선택 → 세로 영상 1개 (1080×1920, 최대 15초)
3. **글자 고치기**: 큰 문구(`Happy Birthday!`), 둘째 줄(`OOO의 생일`), 날짜를 바꿔요. 날짜는 열 때마다 오늘로 채워지고, 영상은 마지막 문구(`사랑해요 ♥`)도 바꿀 수 있어요.
4. **만들기**를 누르고, **저장하기**(또는 폰에서는 **공유하기**)로 받아요.

이미지 탭에서는 사진을 손가락으로 끌어 위치를, 슬라이더로 확대를 조정할 수 있어요.
영상 탭에서는 사진 순서를 ◀ ▶ 로 바꾸거나 ✕ 로 뺄 수 있고, 미리보기를 재생해 볼 수 있어요.

## 알아 두면 좋은 점

- **사진은 서버로 올라가지 않아요.** 모든 처리는 쓰는 기기의 브라우저 안에서만 이루어지고, 만든 파일은 그 기기에 바로 저장돼요. 그래서 기기끼리 자동으로 동기화되지는 않아요.
- **카카오톡·네이버·인스타그램 같은 앱 안의 브라우저에서는 저장이 안 될 수 있어요.** 이럴 땐 페이지 맨 위의 **크롬으로 열기** 버튼을 누르거나, 메뉴의 "다른 브라우저로 열기"를 쓰세요.
- 영상은 브라우저의 WebCodecs(H.264)로 인코딩해서 MP4로 만들어요. 이 기능이 없는 브라우저에서는 화면 녹화 방식으로 대신 만들고, 기기에 따라 webm으로 저장될 수 있어요(만든 뒤 안내가 나와요).
- 큰 사진은 불러올 때 긴 변을 2000px로 줄여서 써요.
- 마지막으로 쓴 문구는 그 기기에 기억해 두었다가 다음에 채워 줘요(날짜 제외).

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 전체(화면, 틀, 이미지·영상 생성 코드가 한 파일에 들어 있어요) |
| `mp4-muxer.js` | 인코딩한 영상을 MP4 파일로 묶는 라이브러리 ([mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.1.3) |

빌드 과정이 없는 정적 페이지예요. 고치려면 `index.html`을 수정하고 `main` 브랜치에 올리면 GitHub Pages가 몇 분 안에 반영해요.

## 내 컴퓨터에서 실행하기

```sh
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 을 열어요
```

`localhost`는 브라우저가 안전한 주소로 취급해서 MP4 만들기가 동작해요. 같은 와이파이의 다른 기기에서 `http://IP주소:8080`으로 열면 안전하지 않은 주소로 보여서 MP4 대신 webm으로 저장될 수 있어요.

## 틀 추가하기

- 이미지 틀은 `index.html`의 `IMG_TPLS` 배열에 `{ id, name, slot, draw(ctx, S) }` 항목을 추가해요. `slot`은 사진이 들어갈 자리이고, `draw`에서 배경과 글자를 그린 뒤 `S.photo(this.slot)`으로 사진을 넣어요.
- 영상 틀은 `VID_TPLS` 배열에 배경 색, 글자 색, 사진 액자 모양(`round` / `polaroid` / `full`), 사진 자리(`slot`)를 정해서 추가해요.
